executeAt

suspend fun <T> Clock.executeAt(instant: Instant, action: suspend () -> T): T

Execute the provided action at or after instant.

The coroutine will be suspended until instant without blocking the thread. If Clock.now returns an Instant greater than the supplied instant, this function executes action without suspending.

suspend fun <T> Clock.executeAt(dateTime: LocalDateTime, timeZone: TimeZone, action: suspend () -> T): T

Execute the provided action at or after dateTime in timeZone.

The coroutine will be suspended until dateTime in timeZone without blocking the thread. If Clock.now returns an Instant greater than the Instant associated with dateTime in timeZone, this function executes action without suspending.

Local time conversion is sometimes ambiguous, and therefore it's recommended to schedule execution in a fixed UTC offset timezone. See LocalDateTime.toInstant for more details.
